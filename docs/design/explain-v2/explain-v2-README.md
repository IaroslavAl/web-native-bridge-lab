# «Как это работает» — макет v2

Выбранное владельцем направление уточнено. Открыть `explain-v2.html` обычным браузером. Установки, Xcode, Node и сервер не нужны. Это не новый RC: действия/данные/версии имитируются и обозначены как макет.

## Что изменилось
- Пять видимых фаз запроса: экран → приложение → сервер → приложение → экран. Подсветка участника, направление стрелок и простые подписи меняются вместе.
- Один главный маршрут: получить каталог → загрузить новый веб-экран → рассчитать заказ → итог.
- Новый экран выделен содержанием и меткой новой возможности. Постоянно указано, что версия установленного приложения остаётся прежней.
- Ответ расположен перед главным действием. В итоговом состоянии убраны повторяющиеся пояснения, чтобы результат, сравнение и версия приложения помещались вместе.
- Инженерные настройки удалены из изображаемого приложения. Контролы сценариев ошибки/неопубликованной версии находятся СНАРУЖИ и свёрнуты по умолчанию — только для обсуждения макета.
- Ошибка не выдаёт результата. Повтор завершает действие. Отсутствие опубликованной версии не подменяется успешным обновлением.
- Загрузка веб-экрана отдельно описана как загрузка экрана, а не как запрос расчёта через native bridge. Макет не утверждает, что обновление публикуется из приложения.

## Проверено исполнением
Playwright Chromium: полный маршрут; последовательность туда/обратно; ошибка и повтор; ожидание опубликованной версии; сброс. Размеры 390×844, 320×740, 1100×900, а также reduced motion на 390×844. Ошибок JS и внешних сетевых обращений нет. Перекрытия соседних блоков и горизонтального переполнения нет. В проверенных мобильных размерах вся изображаемая область приложения (включая главный ответ/кнопку и подпись версии) помещается по высоте. Перед измерением сбрасывалась прокрутка, чтобы автоматический scroll от кликов не маскировал проблему.

Обнаруженное и исправленное: первая компоновка выталкивала нижнюю часть за экран; убраны дублирующие пояснения и уплотнены мобильные отступы. Первые неуспешные QA-прогоны были настоящими отказами, не скрывались. Итоговый результат — `explain-v2-qa.json`.

## Ограничения проверки
Скриншоты сформированы Chromium. Встроенный browser tool ранее заблокирован настройкой системного браузера; независимая визуальная/эстетическая оценка не выполнена. Геометрические проверки не заменяют такую оценку. Safari, реальное iOS-приложение, системные safe areas и Dynamic Type новой реализации ещё не проверены.

## Дизайн-аудит по исходнику и компоновке
Поверхность: Learn — обучение через действие, не технический монитор. Бирюзовый акцент сохраняет выбранный вариант; системный шрифт выбран для привычного iOS-вида и автономного файла. Нет градиента, размытия, декоративных счётчиков и маркетинговых карточек. Три узла — участники реального объяснения, не три рекламные карточки. Убраны повторения текста; настройки макета не входят в основной интерфейс.
