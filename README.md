# Web–Native Bridge Lab

Small, evolving iOS + React laboratory for a generic native HTTP transport behind WKWebView.

Approved mission: [PER-85](https://beldin-dev.atlassian.net/browse/PER-85). The first acceptance target is iOS Simulator only: change the web endpoint, JSON shape and UI without rebuilding or reinstalling the same iOS binary. Native code must not know business endpoints or response models.

See [owner mission](docs/agent/OWNER_MISSION.md) and [agent rules](AGENTS.md). Implementation, run commands and verification evidence are pending; this seed is not a working demo.

No production authentication, deployment, App Store publication, real-device acceptance or full BDUI platform is included.
